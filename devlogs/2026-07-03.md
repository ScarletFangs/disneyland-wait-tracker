# Devlog — 2026-07-03

## Project

Disneyland Wait Tracker — Building the Showtimes and Favorites screens

## Progress

- Built the Showtimes screen listing today's shows with their performance times as chips that wrap onto new lines, with a red badge for shows that have no showings today.
- Found and fixed a timezone bug where showtimes displayed in the early morning, because dart parses timestamps with an offset into utc. Converting to local time before formatting fixed it.
- Built the Favorites screen on a live firestore stream, so the list updates by itself the moment a ride is favorited or unfavorited anywhere in the app.
- Extended Favorites with a second pass that joins current wait times onto each favorited ride, with a three way label covering rides missing from today's data, closed rides, and live waits.
- Decided the failure behavior on purpose: a failed wait time fetch degrades to dashes instead of blanking the screen, and the screen holds on a spinner until the wait data has at least been attempted.

## Reflection

The plan from last session held, but the favorites screen was more complex than I thought it was going to be. It started as a simple list on a firestore stream and grew into two data sources joined in one screen, one that pushes updates on its own and one that I fetch and hold myself. That reversal taught me something about state. A screen is not stateful just because it requests data from a service. It is stateful when it has to remember something between rebuilds that no builder widget is managing for me. The showtimes bug was the other lesson. Shows were displaying at three in the morning because dart parses timestamps with an offset into utc, and I only caught it because the times were exactly seven hours off. I want to be actively testing for this kind of simple mistake in future projects instead of trusting that the data looks right. For error handling I wanted the wait information attempted before the screen loads, and if it fails the screen still loads what it can, so the app shows it still remembers what was favorited.
