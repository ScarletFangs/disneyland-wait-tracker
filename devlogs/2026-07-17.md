# Devlog — 2026-07-17

## Project

Disneyland Wait Tracker — Closing the screen audit and hardening the failure paths

## Progress

- Finished the screen by screen audit from last session: showtimes, auth, and profile all got walked with a deliberate list of states like offline, mid loading, and double taps, which closes the verification phase across all six screens.
- Checked showtime data against the live api and found that meet and greets come back as all day time ranges rather than single performances, so those now display as a start to end range, decided by the shape of the data instead of its type label.
- Fixed a silent dead end where tapping continue as guest with no internet did nothing at all. Guest sign in now reports the same friendly error sentences as the other login paths.
- Both forms now disable their buttons while a request is in flight, which stops double submits, including one that could kill the session and dump a guest back at the login screen.
- Leftover findings like stale event entries and layout polish were filed for the polish pass instead of chased, and the brain fog days ran on small mechanical bites instead of new concepts.

## Reflection

I split the work this time based on what I could already do versus what I needed to look up or learn. I was working through brain fog for most of it, and I did not want to take on anything that needed my full focus to understand because I would have done a bad job. The showtimes fix came from actually looking at the data. Shows that are real performances have their start time equal to their end time, and that small detail determined how I wanted to show the time ranges on screen. The double tap bug surprised me the most because I am still not sure how it sends a guest back to the login screen. It showed me the importance of walking through the project manually sometimes and not purely relying on a code walkthrough, since the code only reflects a perfect situation. The loading flag pattern helps me verify whether information was sent in time and prevents actions when it was not. I do not think I have enough practice to catch those gaps myself just yet, but I feel like I will be able to start thinking in that direction.
